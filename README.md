# Web Scraping and APIs for Humanities Research

*Сourse materials*

The second course of the [Minidegree Digital Humanities](https://github.com/Minidegree-DH) programme, Faculty of Humanities, HSE University, 2026/27. Teaching language: Russian.

📖 **Course website:** <https://minidegree-dh.github.io/miniDH-scraping/>

## About the course

Students learn to collect data for humanities research with Python: how HTTP and web APIs work, how to extract data from static and dynamic web pages, how to query Wikidata with SPARQL, and how to turn the result into a clean, documented dataset. Ethical and legal aspects of data collection are discussed throughout the course. The course follows the rule "an API first, scraping last".

The course builds on *Digital Technologies in Professional Practice* ([miniDH-intro](https://github.com/Minidegree-DH/minidh-intro)) and prepares data-collection skills for *Natural Language Processing & Computer Vision* ([miniDH-NLP-CV](https://github.com/Minidegree-DH/miniDH-NLP-CV)).

## Submitting your work

- **Homework** goes to your personal public GitHub repository, into the folders `hw1/`, `hw2/`, and `hw3/`. Students create this repository in the first session.
- **The final project** is individual: a carefully built and documented dataset for a humanities research question, kept in your personal public repository.
- The best projects are added to the [Student Research Showcase](https://github.com/Minidegree-DH/minidh-student-projects).
- API keys and tokens never go into a repository: keep them in files with the `.token` extension, which are listed in `.gitignore`.

## Two levels

The course is taught at two levels: sections and tasks marked ⭐ are for the advanced level (more open-ended Digital Humanities tasks and additional theory).

## AI assistants

Every task carries an icon:

- 🚫 — no AI; 
- 💬 — AI may only explain errors and unclear points, you write the code yourself; 
- 🤖 — AI is allowed.

In block 1 (sessions 1–2 and HW 1) no code is generated with AI; from session 3, AI is allowed in tasks marked 🤖. If students used AI in homework or the project, they add an `AI_LOG.md` file: the tool, your prompts, what you accepted, what you corrected and why. All tasks can be completed without AI.
