Открытые API и данные

Доступность ресурсов из России меняется. Прежде чем выбрать API для задания или проекта, откройте адрес из его документации без VPN.

Ресурс Что даёт
MediaWiki API Статьи, категории, правки Википедии; без ключа, но нужен заголовок User-Agent; лимиты запросов
Wikidata Query Service SPARQL-запросы к Wikidata; без ключа
Open Library: Developer Center, Search API, выгрузки Открытый библиотечный каталог: книги, авторы, издания; без ключа, User-Agent с контактом даёт более высокий лимит; весь каталог — через ежемесячные выгрузки
Internet Archive Advanced Search Оцифрованные книги, аудио, видео; без ключа
The Met Collection API Коллекция Метрополитен-музея; без ключа
Smithsonian Open Access Коллекции музеев Смитсоновского института; нужен бесплатный ключ api.data.gov
Crossref REST API Метаданные научных публикаций; без ключа
Gutendex Книги Project Gutenberg в общественном достоянии; без ключа
GitHub REST API Репозитории, например DH-проекты; без токена 60 запросов в час
Открытые данные Москвы Объекты культурного наследия, музеи, библиотеки; нужен ключ после регистрации
Национальный корпус русского языка Корпуса русского языка; есть API
Europeana APIs Коллекции европейских музеев, архивов и библиотек; нужен бесплатный ключ; из России открывается не у всех
VK API Данные ВКонтакте; нужно приложение и токен; в заданиях — только по согласованию и без данных о пользователях
