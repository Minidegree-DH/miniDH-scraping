Каталог гуманитарных API

Доступность ресурсов из России меняется. Перед выбором откройте адрес API из документации без VPN и отправьте пробный запрос. Отметка «проверено 13.11» означает, что 13.11.2026 пробный запрос с компьютера преподавателя получил ответ; это не гарантирует, что ресурс будет доступен и вам.

Перед сбором обязательно прочитайте правила использования API: многие из них просят указывать User-Agent с контактом и ограничивают число запросов в секунду. Если источник предлагает готовые выгрузки, большие объёмы данных берут из них, а не через API.
